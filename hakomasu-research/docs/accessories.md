# 配饰与衣装

## 记录格式（`ACDT TAG`，每条 0x50 字节）

条数在 0xCE50，记录从 0xCE60 开始连续存放，最多 246 条。每条是 16 字节头加 16 个 i32：

| 下标 | 含义 |
|---|---|
| 0 | 物品 ID |
| 1 | 推测：类型/变体 |
| 2 | 分类：0 Head，1 Body，2 Hand，3 Leg，4 衣装 |
| 3–8 | 能力值（两组三元组，顺序因物品而异） |
| 9–14 | 推测：附加效果 |
| 15 | 0 |

- 只改条数会被判坏档，必须同时增减实际记录。
- 补记录时，能力值是从同分类、ID 最近的已有记录借来的，xex 里找不到静态能力表，所以不保证和原物品完全一致。

| ID | 件数 | 内容 |
|---|---|---|

| 85–120 | 36 | Hand（085–120） |

| 182–238 | 57 | 衣装：COOL 182–193，CUTE 202–213，COSMIC 220–231；194–201、214–219、232–238 为 DLC 衣装 |
| 247–253、255 | 8 | DLC エクステンドアクセ 01–07、09（ID = 246 + 编号） |

- 有效 ID 一共 246 个，正好等于存档容量：配饰 189 件（本体 144 + DLC 45），衣装 57 件。
- ID 0、239–246、254 没有对应物品；254 应该是从未发行的エクステンドアクセ08。
- 游戏内 Producer 页的"アクセサリー数"显示的是记录总数，所以全满时是 246。

## DLC 交叉核对

12 个 DLC 包（`content/0000000000000000/4E4D07DB/00000002/`）的 `root/common/resources.xml` / `.bxr` 里直接写着配饰 ID 和模型文件的对应，例如 `acc_head_51.acc` = ID 145。

| カタログ | 新配饰 | 备注 |
|---|---|---|
| 1–6 号 | 6、6、6、6、7、6 | 3–6 号另有"レアアイテム"共 12 件，是本体已有配饰（ID 2、24、25、31、55、69、82、97、110、118、138、140）的再贩售 |
| 7–12 号 | 共 8 件エクステンドアクセ | 7 号 2 件、8 号 1、9 号 1、10 号 2、11 号 1、12 号 1 |
| 合计 | 45 | 和存档里的 DLC ID 数一致 |

按部位：Head 15（文件 `acc_head_51–65`）、Body 11（51–61）、Hand 11（51–61）、Leg 8（51–58）。

Extend 衣装共 15 套：`exte01–06`，以及 `exec`、`scwr`、`momo`、`prt2`、`trp2`、`cher`、`race`、`scmz`、`swm2`。

## 游戏里剩下的"？"

全部 246 条都补齐后，Body 剩 1 个"？"、Hand 1 个、Leg 2 个，Extend 衣装页剩 3 个，Head 没有。
这和攻略站表里标成"-"的空位完全一致，是从未发行的预留格，改存档补不出来。

DLC 物品在游戏里一律显示成购物车图标，显示与否取决于有没有 DLC 许可证，和存档里有没有记录无关。
官方说明：删除 DLC 数据可能导致衣装、配饰不显示，甚至存档无法使用。
